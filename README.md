# POCUS MOSCOW Block Planner

Интерактивный образовательный навигатор выбора стратегии регионарной
анестезии по типу операции.

Первая демонстрационная операция — тотальное эндопротезирование коленного
сустава (TKA / ТЭКС). Сценарий показывает переход:

`операция → хирургическая зона → иннервация → покрытие → слепая зона → стратегия`

> Проект не является клинической рекомендацией. Клинические формулировки и
> визуальная карта требуют экспертной валидации перед практическим применением.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверка

```bash
npm run build
npm run lint
```

## Структура

- `app/` — интерфейс и scroll-механика;
- `public/media/` — оптимизированные визуальные материалы;
- `docs/` — Style Bible, промпты и роли LLM;
- `.github/workflows/` — автоматическая проверка сборки.

## Работа с клиническим контентом

Каждое утверждение должно иметь один из статусов:

- `VERIFIED` — проверено экспертом;
- `NEEDS REVIEW` — требует клинической проверки;
- `PROTOTYPE LOGIC` — используется только для демонстрации интерфейса.

Проект не хранит данные пациентов.
